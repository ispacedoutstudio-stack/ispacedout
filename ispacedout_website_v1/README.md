# I Spaced Out website

Static GitHub Pages website. Homepage, Albums as Interiors gallery, Cowboy Carter article, About and Contact pages.

## Publishing
Upload all files and folders in this package to the **root** of your public GitHub repository, preserving folder names. GitHub Pages must be configured to deploy from the `main` branch and `/ (root)`.

**Links:** Internal links use relative paths, so they work both at the temporary GitHub project URL and at the final custom domain.

**Before launch:** Verify external Squarespace image URLs and image rights; replace the placeholder About copy and Contact email. The original product links are retained and have not been checked for availability.
